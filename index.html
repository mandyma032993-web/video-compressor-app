How to Use
1

Upload your video

Drag and drop an MP4 file onto the area above, or click to browse. Only .mp4 files are supported.

2

Choose a compression level

Pick Low, Medium, or High depending on how much you want to reduce the file. Or enter a specific target size in MB.

3

Start compression

Click Compress and keep the tab open. A progress bar tracks each phase: uploading, analyzing, and compressing.

4

Download the result

Once done, click Download compressed video. The file is available for 30 minutes before automatic deletion.

FAQ
What formats are supported?

Input must be MP4. Output is always MP4 (H.264 video + AAC audio).

Is there a file size limit?

No hard limit. Files up to several GB work fine — practical limits depend on your upload speed.

Can I close the tab while compressing?

No — the download link will be lost. Keep the tab open until the download button appears.

The compressed file is larger than the original — why?

The original may already be heavily compressed. Try the High level or set an explicit target size.
